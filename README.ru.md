# Codex Project Trust для BB

Проверка и подтверждение доверия к проекту Codex прямо из треда, который о нём
сообщил. Карточка показывает путь проекта, машину, где работает Codex, и файл
пользовательской конфигурации, который будет изменён. Итоговая кнопка
**Trust project** сохраняет решение через собственный App Server Codex.

## Установка

```sh
bb plugin install 'git:https://github.com/ainurminibaev/bb-codex-project-trust.git@^1.0.0'
```

Нужны BB 0.50.1+ и Codex CLI 0.170.0+, доступный демону машины BB; машина
должна быть подключена. Обновление: `bb plugin update codex-project-trust`
(BB следит за совместимыми тегами). Плагин входит в набор
[bb-config](https://github.com/ainurminibaev/bb-config).

## Использование

1. Откройте тред Codex с предупреждением о доверии к проекту.
2. Нажмите **Review trust** и проверьте детали: доверие позволяет Codex
   загружать локальную конфигурацию проекта, хуки и правила выполнения команд.
3. Нажмите **Trust project**. Codex прочитает изменение при следующем запуске
   среды треда; в BB дайте текущей работе закончиться, затем остановите и
   продолжите тред.

Плагин сверяет предупреждение Codex с текущей рабочей папкой треда и читает
соответствующую конфигурацию на машине. Отсутствующая папка или сменившаяся
рабочая папка запрещают запись. Профили, которые в демоне BB разрешаются иначе,
требуют ручной проверки файла из предупреждения.

Отозвать доверие: удалите запись `trust_level = "trusted"` из показанной
конфигурации Codex и перезапустите среду. Удаление плагина решения Codex не отзывает.
