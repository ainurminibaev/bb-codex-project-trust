---
name: codex-project-trust
description: Explain, use, or troubleshoot Codex project trust cards in BB.
---

Open the affected Codex thread and review the card below its header. The user
can confirm the exact project path, execution machine, and Codex user config.
After a successful save, the new setting is read when the runtime starts again.

If the profile cannot be verified, inspect the thread's current environment
and the original Codex warning. The daemon's Codex installation must read the
same user config path. Do not apply project trust on a user's behalf from an
agent or automation. The plugin provides no agent tool or CLI for accepting it.
